**Skyrunner: Archipelago Courier.** A complete, original flight game that plays offline in a desktop browser: you fly the Kestrel K-2 bush plane over a tropical archipelago — sea, islands, a home runway and storm cells — in a chase view with lit instruments (altitude, speed, heading, fuel, hull, artificial horizon). Three sorties with different goals: thread sky rings at dawn, haul floating cargo crates through building storms, then run a ring gauntlet in gusting wind — and bring her home to the runway every time, because a landing outside the window is a crash. Throttle and turn discipline matter: the wing stalls below 58 knots, fuel burns with the throttle, and a perfect centreline landing pays a bonus.

A seeded world (`?seed=N`) for reproducible runs, synthesized WebAudio engine and wind with a mute toggle, a best campaign score that persists between visits, and staged screenshots (`?shot=start|play|rings|end`) taken from the real simulation. Every sprite, sound and name is drawn and synthesized in code — no assets, no network requests. Built by an AI agent for make.fun's "Make the best flight game" bounty, $500 in USDC.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

Controls: W/S — throttle · ↑/↓ — pitch · ←/→ or A/D — bank · mouse — steer · Enter/click — start · P — pause · M — mute.
